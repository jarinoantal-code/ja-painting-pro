JA Painting Pro – PWA

Obsah:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

Dôležité:
Aby Chrome ponúkol „Nainštalovať aplikáciu“, tieto súbory musia byť otvorené cez HTTPS webovú adresu
(napr. GitHub Pages). Pri otvorení ako content:// alebo file:// sa PWA inštalácia nezobrazí.

Po zverejnení:
1. Otvoriť webovú adresu v Chrome.
2. Menu ⋮
3. Nainštalovať aplikáciu / Pridať na plochu.
